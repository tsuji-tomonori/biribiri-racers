# 周回ゴール・壁接触・マシン特性の改善
状態: do
タスク種別: 修正

## 目的と範囲
全5コースを一周してスタート線に戻る方式にする。分岐の合法ルート、壁の見た目と衝突判定、CPUの復帰、感電演出、4機体特性、ロゴを改善し、Pages公開後まで確認する。

## 原因分析（実装前）
confirmed: finishは画像下部の出口、pointsも出口まで。gatesは130pxごとの一本道で、サンダーガーデンの分岐を許容しない。穴ポリゴンは壁の内側をなぞっており、壁の厚みが走路に含まれる箇所がある。CPUはtick/resetを共有しているが、CPU衝突の直接テストがなく、即座に移動して粒子が画面外へ置き去りになる。4色の機体に性能差なし。
inferred: 壁上に見えるCPUが戻らないのは壁厚みの判定差と復帰演出不足が主因。CPU専用無敵処理は存在しない。
対策: 閉ループの経路、分岐前後の共通チェック区間、壁境界からの距離による機体全体判定、CPU/人共通の接触→感電停止→スタート転送、機体スペックの一元定義。

## UI仕様・アセット計画
左上は重なる文字影を廃し、電気と周回を示すマーク＋読みやすい日本語ワードマークに刷新。選択UIは4つの機体名・長所短所・実設定に基づく性能表示。レースはSTART/FINISHと1 LAPを明示。接触は短い電撃線・輪郭フラッシュ・小さい揺れ、motion reduce時は揺れなし。壁厚を避ける安全域を画面に整合させる。既存5コース画像/機体は保持し、旧出口のGOAL表記は周回仕様に合わせる。

## 受け入れ条件
- [ ] 5コースでスタート線を一周後に越えるとゴール。初回通過/往復/逆走/区間省略は不可。
- [ ] サンダーガーデンの外回り/内回りの合法な分岐でゴール可能。
- [ ] 機体が壁の描画領域へ乗り上げる前に接触する。
- [ ] CPUと人間の全機体で、接触時に進捗をリセットし感電停止後スタートに戻る。
- [ ] 4機体に速度・旋回・チャージ等のトレードオフがありUIと一致する。
- [ ] 新ロゴ、感電演出、復帰、選択、結果を375/768/1440pxとE2Eで確認する。
- [ ] 型検査・単体・E2E・CI・Pages公開後smoke成功。
