# 匿名10人対戦の再構築
状態: do
タスク種別: 機能追加

## 背景と範囲
利用者がWorkの未push作業消失を受けて再構築を指示。最新origin/mainから専用worktreeで再実装する。前回のテスト結果を今回の証拠として流用しない。途中コミットもpushして保存する。

## 受け入れ条件
- [ ] ログイン不要の作成・参加、最大10人、11人目拒否。
- [ ] 入力・位置・接触を同期し、最下位確定時に終了。再接続・退出・ホスト移譲。
- [ ] 全コースGPと毎回コース選択できるフリー。
- [ ] FastAPI/Mangum Lambda、DynamoDB単独DB、AppSync、CloudFront/S3/API GatewayをCDKで構成。
- [ ] Devスタンダード正本とAPI/CDK実装由来文書を自動生成。再生成一致・差分拒否を検証。
- [ ] 厳格な型検査、API/物理/競合/認可テスト、10ブラウザと既存回帰を検証。
- [ ] レポート、push、PR、CI、受入コメントを完了。

## 実装・検証計画
APIとDynamoDB状態機械→ブラウザ連携→CDK/文書生成→単体/ブラウザ検証。READMEとREQ/ARC/DES/OPSを更新する。匿名tokenの非公開、順位の競合、生成物の再現性をセルフレビューする。実AWSデプロイと計測はアカウント未指定につき別途。AWS配備済みとは報告しない。
