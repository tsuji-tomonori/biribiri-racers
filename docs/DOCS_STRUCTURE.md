# 現行文書の構成

種別: 文書索引 / 版: 1.0 / 更新: 2026-09-05

要求は1条件1ファイル、受入条件は同じファイルに記述する。REQは今回の1人用公開版の要求、ARCは実装構造、DESはUI/画像、OPSはCI/CD運用。過去のappと旧UI設計は置換した。履歴のtasks/reportsを現行要件と混同しない。

- `1_要求_REQ/11_製品要求_PRODUCT/01_機能要求_FUNCTIONAL`: 観測可能なゲーム動作
- `1_要求_REQ/12_制約_CONSTRAINT`: 技術制約
- `1_要求_REQ/21_受入基準_ACCEPTANCE`: 受入項目索引
- `2_アーキテクチャ_ARC`: 構造と状態
- `3_設計_DES`: UIとアセット
- `4_運用_OPS`: 開発・公開・復旧
