# DES-001 UI・アセット

種別: UI設計 / 状態: 実装済み

メニューは左にモード・操作・開始、右に選択中のコース全景と5枚のカード。1440pxでは2カラム、375pxでは縦配置。青・白・ピンク、太い輪郭、丸いボタンを参照画像から採用する。画面画像のピクセル完全一致は要件にしない。

レースは追尾カメラ、機体の向き・ダッシュ軌跡・衝突復帰、全体地図を表示する。HUDには実際の順位、経過時間、進行度、接触数、速度、チャージを表示。カウントダウン・停止・終了が識別できる。Canvas以外の操作はネイティブbutton/select/radio、モーダルはdialogでフォーカスを管理。主要操作は44px以上、キーボードフォーカス表示、動きを抑えるOS設定を尊重する。

参照元: project_sourcesの03/06/16が画面デザイン、04/07/08/14/15がコース画像。カービィ等のキャラクター画像、製品ロゴ、音源は使用しない。押して減速・離して加速する操作の方向性を参考にする。全5コースはImageGenで旧GOALアーチ・柱・出口を除去し、閉じた外壁と連続道路に再生成した。画像内の左側START / FINISHが共通線。案内板による隠蔽は行わない。描画する進行矢印は物理経路から生成し、外壁ポリゴンは再生成画像の道路端に合わせる。

スクリーンリーダーでの走路認識や実機ゲームパッドの操作性は未検証。レスポンシブとキーボード操作は自動テストと実画面確認の範囲を作業報告に記録する。


## 周回版のUI
Brand.astroとfavicon.svgは電気＋周回のオリジナルSVGマークを共通利用する。日本語ワードマークの多重縁取りと傾きを廃する。機体選択にはバランス/最高速/旋回/チャージの識別、選択機体の名前・長所短所・設定値を表示する。
接触時は機体周囲の電撃線・明るい輪郭、最大4pxの短い横揺れ、メッセージ、順位行の感電/復帰状態で通知する。reduced motionでは揺れと粒子を停止する。画面テストのelectric-impact/return-to-start画像で接触から転送までを確認する。
