# DES-001 UI・アセット

種別: UI設計 / 状態: 実装済み

メニューは左にモード・操作・開始、右に選択中のコース全景と5枚のカード。1440pxでは2カラム、375pxでは縦配置。青・白・ピンク、太い輪郭、丸いボタンを参照画像から採用する。画面画像のピクセル完全一致は要件にしない。

レースは追尾カメラ、機体の向き・ダッシュ軌跡・衝突復帰、全体地図を表示する。HUDには実際の順位、経過時間、進行度、接触数、速度、チャージを表示。カウントダウン・停止・終了が識別できる。Canvas以外の操作はネイティブbutton/select/radio、モーダルはdialogでフォーカスを管理。主要操作は44px以上、キーボードフォーカス表示、動きを抑えるOS設定を尊重する。
