# REQ_FUNCTIONAL_004 合法ゴール

種別: 機能要求 / 出所: 今回の公開依頼・継続ゲーム仕様 / 優先度: 必須 / 状態: 検証済み / 版: 1.0

## 要求
システムはコースを一周して正方向にスタート線へ戻った機体だけを完走とする。

## 受け入れ条件
5コースで初回のスタート通過は完走にならず、一周後に同じ線へ戻ると完走する。逆走・区間省略・ライン往復100回は不可。サンダーガーデンの内側・外側ルートはともに完走可能。
