# REQ_FUNCTIONAL_003 接触復帰

種別: 機能要求 / 出所: 今回の公開依頼・継続ゲーム仕様 / 優先度: 必須 / 状態: 実装済み・公開検証中 / 版: 1.0

## 要求
走路外との接触時、システムは機体の当該走行進捗をスタート状態へ戻す。

## 受け入れ条件
位置、順路ゲート、進行度、速度、チャージをリセットし、接触数を加算する。
