# ARC-001 ゲーム構造

種別: アーキテクチャ / 状態: 実装済み

Astroが静的UIを生成し、TypeScriptモジュールが起動する。`tracks`の座標を`geometry`が経路・順路ゲートに変換し、`physics`が各機体を1/120秒刻みで更新する。`Session`は状態・カウントダウン・順位・終了を管理する。Canvas描画、音、DOMは物理から分離する。

通常遷移: menu → countdown → racing → finishing → finished。countdown/racingはpausedから元の状態へ戻る。リトライは新しいSessionを作成する。画面離脱・非表示では時間と入力を停止する。レースは最初の完走または180秒で終了、練習は単独完走まで走れる。

衝突は中心+半径23の周辺16点を走路ポリゴンで検査し、位置・速度・経路・チャージを初期化する。ゴールには全順路ゲートの正方向通過と距離条件が必要。CPUも同じ衝突・チャージ・ゴール判定を使用する。高速な描画と更新頻度を分離し、単フレーム上限0.25秒で復帰時の飛び越しを防ぐ。

画像の座標と当たり判定は1254四方で共通。コース変更で勝手に別画像を出さない。画像取得失敗は明示し開始を禁止する。外部API、個人情報、認証、ランキングサーバーはない。配信は意図的に公開する非機微のゲームデータだけ。管理権限はGitHub Actionsのdeploy jobに限定する。
