# Astro一人用版の再構築・公開確認

状態: done / 2026-09-05

## 受けた指示・要件
旧資産を置換可能、Astro/TypeScript、一人で遊べるレーシングゲーム、単体/E2E、CI/CD、GitHub Pages公開と公開後の動作確認。

## 判断・実施
既存mainから専用worktreeを作りroot Astro構成へ再構築。旧appと製品文書を置換し、AGENTS/skills・作業履歴・git-secretsは保持した。提供5コースと前サンプルのオリジナル4色機体を利用。操作は自動加速、押して減速/チャージ、離してダッシュ。CPU3台との対戦と単独練習を実装した。

入力・走行・経路・勝敗・描画・音を分離。1/120秒固定更新、順路ゲート、正方向ゴール、衝突復帰、停止/再開、リトライ、画像取得失敗と再試行を実装。Astroのbase pathをPages用に設定。UIの順位・タイム・進行・結果は走行状態に由来する。オンラインなど未実装の操作は表示しない。

## 指示への適合・制約
依頼された一人用、Astro/TypeScript、単体/E2E、CI/CD、Pages公開、公開後確認を満たした。秘密情報や外部API、個人情報、認証、サーバー保存はなく、公開対象は非機微の静的ゲームだけ。deploy jobだけがPages書込権限を持つ。GitHub App経由でソースツリーを反映し、ローカルのgit tree SHAとの一致を確認した。
